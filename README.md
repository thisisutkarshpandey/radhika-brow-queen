# Radhika the Brow Queen — Feminine Redesign

A clean, feminine, mobile-first Next.js website concept for a private beauty studio in Southwest Edmonton.

## Run locally on port 3001

```bash
npm install
npm run dev -- -p 3001
```

Open http://localhost:3001

## Deploy

Push the project to GitHub and import the repository into Vercel. Next.js will be detected automatically.

## Before publishing

- Confirm the full service list and pricing.
- Confirm appointment hours.
- Ask permission before publishing the exact residential address.
- Add approved client/work photos if Radhika agrees.
- Replace the generic Google search link with her exact Google Business review URL.
